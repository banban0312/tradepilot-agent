# 手工验收文件

本目录全部使用合成示例数据，对应本机 seed 中的华北部门、`TP-DEMO-SALES-N1` 合同和螺纹钢（HRB400 12mm，合同单价 3,500 元/吨）。请使用有华北部门权限的经办人登录。

| 文件 | 上传位置 | 预期 |
|---|---|---|
| `01-正常订单.xlsx` | 侧栏“批量导入” | 1 个正常组，金额 3,500 元，可建立批次继续处理 |
| `02-正常与错误数量.xlsx` | 侧栏“批量导入” | 1 个正常组、1 个需修正组；错误定位到 `订单明细!J3` |
| `03-超额订单.xlsx` | 侧栏“批量导入” | 金额 175,000 元；在示例合同余额 150,000 元时提示超额 |
| `04-销售订单文本.pdf` | 智能提单 → PDF / 图片 | 带文字层，检查字段提取、页码和来源证据 |
| `05-销售订单扫描.pdf` | 智能提单 → PDF / 图片 | 扫描版，检查本地 OCR 和字段确认 |

PDF 可搭配描述：“请根据上传的销售订单需求单生成草稿，缺少信息先向我确认。”上传后核对提取结果，再继续处理。

这些文件不会自动批准订单；批次创建后会运行真实任务。正式订单仍须有权限的审批人批准当前草稿版本。模型、MCP、OCR 配置须可用；示例单据不代表真实合同。

若主数据或合同余额已被修改，金额和关联校验的实际结果应以当前服务端事实为准。请勿上传本目录以外的真实业务资料进行演示。
