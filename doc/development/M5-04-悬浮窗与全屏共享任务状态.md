# M5-04 悬浮窗与全屏共享任务状态

## 实现范围

- 在应用外壳中提供可收起、拖动和全屏切换的智能提单悬浮窗，记住悬浮窗位置。
- 通过 Pinia 共享当前任务快照、消息、等待状态、草稿编辑缓冲、未发送补充文本和任务事件游标。
- 任务事件订阅由共享状态统一管理。切换全屏与悬浮窗不会重新建任务或开第二条事件流；事件按服务端单调 `seq` 去重，EventSource 重连继续使用 `Last-Event-ID`。
- 等待补充可以在悬浮窗提交到原任务；审批、草稿细节继续在全屏工作台处理。收起悬浮窗只隐藏界面，不停止后台任务。

## 验收

```powershell
pwsh -NoProfile -File code/scripts/verify_issue_032.ps1
```

`uv` 执行 Python 验收入口，再运行 Vitest 行为测试和前端生产构建。测试覆盖同一任务复用快照/事件流、保留未发送文本和未保存草稿、重复事件去重，以及退出会话时关闭事件连接。验证不启动 Worker、不调用在线模型、不操作业务订单，也不重启主开发服务。

原型 `04-order-center-widget` 用于悬浮面板位置、折叠和任务提示；`25-draft-edit` 用于全屏草稿编辑与待审批状态。数据继续来自真实任务 API 与 SSE，不使用原型示例数据。
