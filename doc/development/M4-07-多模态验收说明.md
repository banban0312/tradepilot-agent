# M4-07 多模态文件验收

## 固定标注集

输入及人工标注保存在 `code/tests/fixtures/m4_multimodal_cases.jsonl`；扫描件图片为 `code/tests/fixtures/m4/image_material_conflict_001.png`。测试在临时目录从固定文本生成文本型、扫描型和混合 PDF，再对固定图片运行本地 Tesseract。XLSX 用例覆盖同组多行及组内主档冲突。

统计只针对固定标注字段：关键字段准确率 = 完全匹配的标注字段数 / 标注字段总数；覆盖率 = 至少输出一个候选的标注字段数 / 标注字段总数；候选精确率 = 与标注值精确匹配的候选数 / 输出候选数。多值歧义单独统计是否全部返回冲突候选并要求人工确认，不计入单值准确率。质量目标为关键字段准确率至少 90%、歧义待确认率 100%，每次运行都输出实际样本量和三项比率。

## 覆盖范围

- 文本型、扫描型及混合 PDF 的真实解析、页码、文本范围 / OCR 框证据。
- 图片 OCR 的物料别名、数量与多规格冲突；从识别原文进入真实物料候选接口时，不唯一匹配必须等待人工选择。
- Excel 同一订单多行分组、明细数量、金额、组主档冲突及源单元格定位；预览不写正式订单。
- 与既有验收入口合并回归：加密/损坏/超限/伪类型、存储完整性、附件越权、文档提示注入、解析审计和业务副作用检查。

## 执行方式

```powershell
pwsh -NoProfile -File code/scripts/verify_issue_028.ps1
```

脚本需要 Docker、`code/backend/.env` 中可用于构建的数据库配置、镜像源网络和本地 Tesseract 镜像依赖。每次使用随机 Compose 项目、独立数据库与附件卷、临时高熵演示口令；不读取或转发模型/OCR API 密钥，不连接主开发服务。验证后只清理本次隔离资源，并恢复当前 PowerShell 进程环境变量。
