# M5-06 运行配置与操作审计

## 能力范围

- 管理员可更新模型、OCR、MCP、超时、重试、轮数、工具调用与并发限制、业务时区、演示审批模式及轨迹/附件留存天数。
- 首个任务创建时，服务会将部署环境中的非敏感运行参数冻结为基线版本，之后每个新任务均绑定一个存在的配置版本。
- 更新会创建不可变版本并追加审计事件；任务创建时记录当前配置版本，Worker 按已绑定版本恢复参数。历史任务不随当前配置变更。
- 审计仅系统管理员可查，支持操作、操作者、任务、输入 SHA-256 摘要及时间范围筛选，并提供稳定时间/ID 游标。
- 配置与审计响应从不包含密钥。模型/OCR 密钥使用 `RUNTIME_CONFIG_ENCRYPTION_KEY` 通过 Fernet 加密后单独写入凭据表，不进入配置快照 JSON 或审计输入；UI 输入框留空表示保持现值，读取时只显示配置状态。所有 API/Worker 副本必须共享同一加密密钥。
- 超额规则不可配置关闭。本人审批模式仅在部署环境已显式开启演示模式且任务绑定显式演示审批版本时生效；其他任务必须由另一位获授权的审批人批准。
- 留存策略保护活动任务和已有订单；附件内容读取仍走原有独立授权接口。审计元数据不随轨迹或附件到期而删除。

## 验证

在仓库根目录运行：

```powershell
pwsh -NoProfile -File code/scripts/verify_issue_034.ps1
```

脚本通过 `code/scripts/verify_issue_029.ps1 -IssueOnly -Issue034` 在随机 Compose 项目、独立数据库和附件卷中运行迁移、Alembic schema check、Ruff、Python 编译、前端构建及 `test_issue_034.py`。仅清理自身随机 Compose 项目，不启动 Worker、不调用在线模型、不重启默认开发容器。

测试覆盖非管理员拒绝配置/审计访问、版本冲突保护、配置创建与版本递增、任务绑定旧版本、密钥字段拒绝及配置变更审计回查。测试使用演示管理员和业务经办人固定角色，演示密码由隔离脚本随机生成。该验收为隔离服务集成验证，不代表在线模型或外部 OCR/MCP 联调通过。

## 凭据与运行说明

非敏感运行参数保存于 PostgreSQL 配置版本中。运行时密钥加密密钥由 `code/backend/.env` 或部署密钥管理器注入，可用 `cryptography.fernet.Fernet.generate_key()` 生成。加密密钥丢失或更换后，旧配置版本中的凭据无法解密，Worker 会明确失败，不会回退成虚假成功；需先用原密钥重新提交凭据或恢复密钥。MCP 上下文签名密钥继续由部署环境管理。

旧配置版本与任务引用保留用于审计，未提供删除历史版本或审计行的操作。改变留存天数只影响后续清理任务；清理前应在部署流程中依据变更审阅影响范围。
