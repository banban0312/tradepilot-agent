# 自动评测报告与指标

Issue #38 为 M6-03 提供评测报告的计算口径，具体运行命令见 [评测运行说明](../../code/evals/README.md)。

## 输出文件

- `summary.json`：运行元数据、分类计数、安全不变量、字段/工具/规则/幂等/恢复/Token/耗时指标。
- `cases.jsonl`：逐例输入、预期、实际状态、失败断言、错误码、任务/轨迹引用和 span ID。
- `report.md`：分类摘要、指标表、字段分组和逐例预期/实际摘要，可直接阅读。

JSON、JSONL 与 Markdown 使用同一次结果对象生成；敏感字段在所有导出中递归脱敏。

## 计算口径

字段精确匹配以已执行且可判定的案例中预期标注的字段为分母。缺字段计入分母且不计匹配，同时降低字段覆盖率。`field_metric_scope` 披露跳过和执行错误中未计分的标注字段。字段结果按字段路径、持久化证据的来源类型、文件 MIME 类型分组；缺少实际证据的来源记为 `unavailable`。

工具选择检查案例必需工具是否被模型选择，且全部所选工具属于该案例允许集合。工具执行率只统计真实工具 span。参数校验另报接受和拒绝数，拒绝非法输入本身不当作成功工具调用。规则阻断只对预期 `BLOCKED_RULE` 的案例计分；安全类分类保留独立通过率。

Token 总量只累计服务实际返回的 token 字段，零观测时 JSON 为 `null` 且显示覆盖率。模型、工具和评测单例耗时使用实际 span 毫秒和本地单调时钟；人工等待不是本 CLI 评测的观测量，显示为 unavailable。

运行元数据包含代码版本、运行环境、模式、数据集/夹具版本、随机种子、模型配置摘要、提示词与工具 Schema 摘要；哈希只覆盖非敏感配置项。报告写入前清除凭据字段并遮蔽常见 API key 格式。
字段分母由 `expected.field_labels` 明确指定；旧案例没有该字段时，仅统计评测服务定义的业务抽取字段白名单，审批状态、重放次数、数据库行数等执行事实不混入抽取准确率。

参数校验计数以真实 `TOOL` span 代表请求已通过参数校验并执行，以 `function_calling.tool_argument_validation` 规则错误 span 代表拒绝；未生成这两类证据时不推测结果。
缺失必填字段的案例以 `expected.fields.<字段>: null` 表示该字段在当前等待态不应生成；这类字段不进入必评提取分母。已标注的非空字段若实际缺失，则计为提取遗漏并降低覆盖率。
